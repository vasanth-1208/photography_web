# Lensora — Photography Portfolio & Gallery

A modern photography portfolio website designed to showcase photographs through a clean, elegant, and category-based gallery experience.

## 📸 Overview

**Lensora** is a responsive photography website built to present different styles of photography in an organized and visually appealing way.

The project separates photography into dedicated categories such as:

* 🌄 Landscape Photography
* 👤 Portrait Photography
* 🐾 Wildlife Photography

The website focuses on simple navigation, visual presentation, and a clean photography-oriented design.

## ✨ Features

* Clean photography portfolio interface
* Dedicated photography categories
* Landscape photography gallery
* Portrait photography gallery
* Wildlife photography gallery
* Responsive page layout
* Shared CSS styling across pages
* Simple and lightweight static architecture
* Easy to customize with personal photographs

## 🎯 Project Objective

The goal of Lensora is to provide photographers with a simple digital platform for showcasing their work without the complexity of a large content-management system.

The website organizes photographs into meaningful categories, making it easier for visitors to explore different photography styles.

## 🗂️ Photography Categories

### 🌄 Landscape

Showcases natural environments, scenery, mountains, skies, architecture, and outdoor compositions.

### 👤 Portraits

Dedicated section for portrait photography and human subjects.

### 🐾 Wildlife

Showcases wildlife and nature photography.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/vasanth-1208/Lensora.git
```

### 2. Navigate into the project

```bash
cd Lensora
```

### 3. Run the website

Since this is a static HTML/CSS project, open:

```text
index.html
```

in a web browser.

You can also use a local development server such as VS Code Live Server.
